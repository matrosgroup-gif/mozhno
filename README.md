# МОЖНО

Минимальная веб-версия пространства мечтаний.

- Круг из 8 интерактивных фотосекторов
- Добавление мечт и необязательных шагов
- Три визуальные темы
- Сохранение в localStorage (только на данном устройстве)

Для публикации: GitHub → Settings → Pages → Deploy from a branch → main / root.

Фотографии загружаются с Unsplash и требуют подключения к сети. ИИ-генерация и синхронизация между устройствами пока не реализованы.
